AI Systems · 1/2

Agent workflow kernel · self-host developer tool

Agent Workflow Kernel

Ops-Cure Kernel

orchestration, remote_codex, and chat store their state and events through the same Space / Actor / Event / Behavior model.

  • Agent tasks, remote execution, and chat use different commands and screens but need the same state and event records.
  • I built a Space / Actor / Event core on FastAPI + SQLite, then added Discord transport, a behavior registry, and three runtimes.
  • orchestration, remote_codex, and chat now write state and execution records through the same model.
Self-host Developer Tool

DeskRelay

A self-host developer tool that remotes Claude Code sessions running on your own PC to a browser or mobile. A single server PC runs site-frontend, site-backend, and a connector daemon. Other PCs in the same LAN or Tailscale register as devices.

  • I wanted to check my local Claude Code sessions elsewhere without moving repos, shells, or tokens off each PC.
  • I built the Solid + Vite UI, Hono + Bun server, PC connector, Claude behavior, and Capacitor Android app.
  • The tool is public at github.com/darkhtk/deskrelay, and I use it every day across my own PCs.

AI Systems · 2/2

Local LLM R&D · mobile RAG product

Local LLM R&D

GenWorld + Ollama

Ported a Phaser 3 TS-based RPG to Unity 2D C# while designing a local Ollama LLM-backed NPC cognition / dialogue system. The game uses local LLM dialogue when available and a rule-based dialogue graph when the service is offline.

  • The game and NPC conversations have to keep running when the local LLM stops responding.
  • I store NPC memory, mood, and skill state, and open a predefined dialogue graph on timeout or in offline mode.
  • The same NPC uses generated dialogue while Ollama is available and rule-based dialogue when it is not.
Mobile RAG Product

Oracluna Tarot

At oracluna.com, users choose a concern, shuffle and cut the deck, pick from a 78-card wheel, receive an interpretation, and save or share the result.

  • On a phone, users need to browse all 78 cards without losing their picks or their current place in the deck.
  • I built the card wheel and selection slots, then sent spread position, orientation, and Qdrant results to Ollama or OpenAI.
  • Question entry, card selection, readings, saving, deletion, and image sharing are live at oracluna.com.
NPC runtime state

Mood and relationship values are shown inside the game loop for debugging.

Saved reading

The result screen reopens saved readings and provides image sharing from the browser.

Industrial Software · 1/2

Robotics control · operator tooling

Industrial XR × Robotics

VR Robot Teleoperation

I passed Quest 3 input through Unity and a Flask bridge to a Doosan A0912. The first version used RoboDK; I later added calibration, safety rules, and an in-house Jacobian IK solver.

  • I had to map Quest 3 input into robot coordinates and keep the robot inside defined movement limits.
  • I implemented input filtering, coordinate transforms, bridge APIs, safety boxes, deadman logic, resend control, and IK.
  • At BEXCO, I demonstrated the live robot with movement limits, calibration, and an operator stop control.
Simulation Tooling · Digital Twin

DXCenter

I built nine Unity EditorWindow tools so LG Energy Solution content creators could map data and validate assets without editing code.

  • Developers were repeating scene and data setup whenever production content changed.
  • I put state management, undo, data mapping, preview/runtime separation, and validation into EditorWindow tools.
  • Content creators and operators can now handle repeated setup and checks themselves.
These projects cover robot control, BIM section tools, EditorWindow tooling, and manufacturing ERP installed, checked, and handed over to operators.

BIM Runtime Tooling

WatchBIM

A Unity BIM runtime with a custom hit engine, station-based cross-section generation, a 2D analysis viewer, and camera controls for inspecting large models.

  • Operators needed to pick the right element in a large BIM scene and inspect a section without leaving the runtime.
  • I implemented triangle caching, hit filters, geometry jobs, plane intersection, segment grouping, and 3D-to-2D conversion.
  • The same viewer now shows the selected section, linked 2D analysis, and slope labels.
