Self-host Developer Tool

DeskRelay

내 PC 에서 실행되는 Claude Code 세션을 브라우저·모바일에서 안전하게 원격 조작하는 self-host 개발자 도구. 서버 PC 한 대가 site-frontend, site-backend, connector daemon 을 띄우고 LAN/Tailscale 안의 다른 PC 를 디바이스로 등록합니다.

  • repo, shell과 token은 각 PC에 둔 채 다른 자리에서 제 Claude Code 세션을 확인하고 싶었습니다.
  • Solid + Vite 화면, Hono + Bun 서버, PC connector, Claude behavior와 Capacitor Android 앱을 만들었습니다.
  • github.com/darkhtk/deskrelay에 공개했고, 여러 PC의 제 세션을 관리할 때 매일 쓰고 있습니다.

Local LLM R&D

GenWorld + Ollama

Phaser 3 TS 기반 RPG 를 Unity 2D C# 로 포팅하면서, 로컬 Ollama LLM 기반 NPC 인지·대화 시스템을 설계했습니다. 로컬 LLM을 사용할 수 없으면 규칙 기반 대화 그래프로 전환하도록 만들었습니다.

  • 로컬 LLM이 응답하지 않아도 게임과 NPC 대화는 멈추지 않아야 했습니다.
  • NPC 기억, mood와 skill 상태를 저장하고 timeout이나 오프라인 상태에서는 미리 만든 대사 그래프를 엽니다.
  • LLM이 연결되면 생성 대화를 쓰고, 끊기면 같은 NPC가 규칙 기반 대화를 계속합니다.
Mobile RAG Product

Oracluna Tarot

oracluna.com에서 고민을 고르고 카드를 섞고 자른 뒤, 78장 카드 휠에서 직접 뽑아 해석을 저장하거나 공유할 수 있습니다.

  • 휴대폰에서 78장을 훑는 동안 뽑은 카드와 덱의 현재 위치를 놓치지 않게 해야 했습니다.
  • 카드 휠과 선택 슬롯을 만들고, 배열 위치·정역방향·Qdrant 검색 결과를 Ollama/OpenAI에 전달했습니다.
  • 질문, 카드 선택, 해석, 저장, 삭제와 이미지 공유를 oracluna.com에서 운영하고 있습니다.
NPC 런타임 상태

mood · 관계 상태로 로컬 LLM 행위를 게임 루프 안에서 검사 가능하게.

Industrial XR × Robotics

VR 로봇 원격 조작

Quest 3 입력을 Unity와 Flask 브리지를 거쳐 Doosan A0912에 전달했습니다. RoboDK로 시작해 캘리브레이션과 안전 로직을 붙였고, 이후 사내 Jacobian IK 솔버로 확장했습니다.

  • Quest 3 입력을 산업 로봇 좌표에 맞추고, 로봇이 정해 둔 범위를 벗어나지 않게 해야 했습니다.
  • 입력 필터, 좌표 변환, 브리지 API, 안전 박스, deadman, resend 제어와 IK를 구현했습니다.
  • 부산 BEXCO에서 실제 로봇의 이동 제한, calibration과 운영자 정지 제어를 포함해 시연했습니다.
Simulation Tooling · Digital Twin

DXCenter

LG Energy Solution 콘텐츠 제작자가 코드 없이 데이터를 매핑하고 자산을 검증할 수 있도록 Unity EditorWindow 9개를 만들었습니다.

  • 콘텐츠를 바꿀 때마다 개발자가 Unity 씬과 데이터를 다시 손보는 일을 줄여야 했습니다.
  • 상태 관리, undo, 데이터 매핑, preview/runtime 분리와 검증 기능을 EditorWindow에 넣었습니다.
  • 콘텐츠 제작자와 운영자가 반복 설정과 확인 작업을 직접 처리할 수 있게 됐습니다.
로봇 제어, BIM 단면, EditorWindow 도구, 제조 ERP를 실제 운영자와 함께 설치하고 검수해 인계한 작업입니다.

BIM Runtime Tooling

WatchBIM

대용량 BIM 모델을 런타임에서 선택하고 자를 수 있도록 커스텀 히트 엔진, station 기반 단면, 2D 분석 뷰어와 카메라 도구를 만들었습니다.

  • 대용량 BIM 장면에서 원하는 부재를 정확히 고르고 런타임에서 단면을 확인해야 했습니다.
  • 삼각형 캐시, hit 필터, geometry job, 평면 교차, segment grouping과 3D→2D 변환을 구현했습니다.
  • 운영자는 선택한 위치의 단면, 연결된 2D 분석과 경사 라벨을 같은 뷰어에서 확인합니다.
