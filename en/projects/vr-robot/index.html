// industrial · xr · robotics

VR Robot Teleoperation.

quest 3 → unity → flask → robodk → doosan a0912

I passed Quest 3 controller input through Unity and a Flask bridge to a Doosan A0912 robot. After adding movement limits and stop conditions, I ran a live robot demo at BEXCO in Busan. I later built an in-house Jacobian IK solver to reduce the RoboDK dependency.
