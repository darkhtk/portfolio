// industrial · erp · full-stack

SEMS ERP.

mobile-first · role workflow · fastify/typescript · mysql

A manufacturing ERP that ties together orders, BOM, materials, production, approvals, inventory, and shipping that used to live across spreadsheets and verbal handoffs. The focus was not an admin lookup screen, but a workbench where each role can finish today's work directly.

[ WORKFLOW ] ORDER TO SHIPPING
// problem

Turning status that lived in people's heads
into a system flow.

When sales orders, material stock, production progress, and approvals sit in separate documents and chat threads, teams spend time asking around just to find the current state.

SEMS connects order registration → BOM review → material shortage calculation → picking, purchasing, and receiving → work orders and process tracking → completion requests and approvals → finished-goods stock → shipping.
