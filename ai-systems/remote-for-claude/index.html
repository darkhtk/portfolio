AI Systems · Product Case Study

DeskRelay

사용자가 직접 self-host한 환경에서 자기 PC의 claude CLI를 브라우저 또는 선택적 모바일 shell로 다루는 오픈소스 도구입니다. 사이트 백엔드는 UI와 등록된 디바이스를 관리하고, PC connector daemon은 로컬 실행, 파일, shell, Git, MCP, Claude 인증을 보유합니다.

역할

제품 아키텍처, connector runtime, self-host backend, frontend UX, 디바이스 생명주기, 스크린샷, 문서화를 설계·구현했습니다.

문제

에이전트 작업은 사용자의 repo, shell, token이 있는 PC에서 가장 강합니다. 하지만 그만큼 작업 흐름이 한 키보드에 묶입니다.

접근

실행은 로컬에 둡니다. self-host 사이트 백엔드를 띄우고 각 PC를 daemon URL과 token으로 등록해 private network 위에서 좁은 브라우저/모바일 제어면을 제공합니다.

상태

오픈소스 self-host 제품입니다. PC server script, site token login, local connector 자동 등록, Settings -> Devices 검증, remote chat, diagnostics, 문서가 연결되어 있습니다.

§ 01 · Product surface

백엔드 배관만이 아니라 실제 제어면까지

스크린샷은 실제 제품 표면을 보여 줍니다. 채팅 이어가기, 내비게이션, 디바이스 등록, 선택 디바이스 진단, 설정 화면을 목업이 아니라 제품 증거로 배치했습니다.

DeskRelay 제품 캡처를 README/manual의 self-host 흐름에 맞춰 사용했습니다.

§ 02 · Architecture

원격 UI, 로컬 실행

사이트는 제품처럼 느껴져야 하지만, 민감한 실행 표면은 사용자의 PC에 남아야 합니다.

End-to-end path
Browser → Site Backend → Connector Daemon → Claude CLI

백엔드는 UI와 디바이스 registry를 맡고, 작업·파일·인증은 제어 대상 PC에 남습니다.

BrowserSolidJS UI, chat, settings, approvals
Site backendHono/Bun routes, site token, device registry
ConnectorBun daemon, daemon token, workspace roots
PCclaude CLI, files, shell, Git, MCP, auth
hub바깥은 제품 shell, 안쪽은 사용자 PC의 runtime authority.
System slices

Frontend. SolidJS + Vite SPA. locale, device picker, chat, diagnostics, approval modal, workspace picker, image preview, 선택적 Capacitor wrapper.

Site backend. Hono/Bun self-host process. PC server script가 backend를 띄우고 site token을 출력하며, 브라우저 UI와 등록된 connector daemon URL을 관리합니다.

Connector. 제어 대상 PC마다 실행되는 Bun daemon/CLI. 인증된 daemon URL과 /status를 제공하고 workspace roots를 보유하며, 파일·shell·Git·MCP·Claude auth를 그 PC에 남깁니다.

Operations. manual은 Tailscale, WireGuard, private LAN, VPN을 권장하고 connector daemon port를 public internet에 직접 노출하지 말라고 명시합니다.

§ 03 · Device lifecycle

디바이스 등록은 운영 기능이 아니라 제품 UX입니다

어려운 부분은 디바이스를 추가하는 것만이 아닙니다. 브라우저, self-host backend, connector daemon이 무엇에 접근 가능하고 무엇이 안전한지 같은 상태를 보게 만드는 것입니다.

Register

Daemon URL, label, token

대상 PC는 private-network host/port와 workspace roots로 connector daemon을 실행합니다. Settings -> Devices에서 daemon URL, label, daemon token을 등록합니다.

Validate

사용 전 status 검증

백엔드가 connector /status endpoint를 확인하고, 잘못된 URL이나 token은 디바이스로 등록하지 않습니다.

Operate

전환, 진단, 이어가기

sidebar에서 디바이스를 전환하고, settings에서 연결 진단을 보며, 세션은 이어가기·fork·새 workspace 시작으로 나뉩니다.

§ 04 · Trust boundary

private-network 우선, 로컬 권한은 로컬에

README/manual의 경계는 의도적으로 분명합니다. DeskRelay에는 hosted account, payment flow, managed relay, 필수 app package가 없습니다. 사용자가 site backend와 connector daemon을 직접 띄우고, Tailscale, WireGuard, private LAN, VPN 같은 경로를 권장합니다.

이 구분은 중요합니다. 시스템 형태가 보장하지 않는 privacy claim보다, 스크린샷·문서·아키텍처가 같은 경계를 말하게 만드는 쪽을 선택했습니다.
