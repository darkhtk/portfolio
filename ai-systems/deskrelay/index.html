DeskRelay

GitHub README 기준 DeskRelay는 내 PC에서 실행되는 Claude Code를 브라우저에서 제어하는 self-host 개발 도구입니다. 서버 PC 한 대가 site-frontend, site-backend, local connector daemon을 띄우고, 같은 LAN 또는 Tailscale 안의 다른 PC를 디바이스로 등록해서 씁니다.

기준

이 페이지는 공개 GitHub 저장소의 README, docs/MANUAL.md, package metadata, manual screenshots만 기준으로 다시 작성했습니다.

문제

에이전트 작업은 사용자의 repo, shell, token이 있는 PC에서 가장 강합니다. 하지만 그만큼 작업 흐름이 한 키보드에 묶입니다.

접근

서버 PC를 띄우고 브라우저 UI로 들어간 뒤, 메인 화면의 다른 PC 등록 명령을 대상 Windows PC에 실행해 connector와 device registry를 연결합니다.

상태

저장소 버전은 v0.0.0입니다. README에는 설치, 접속 URL과 token, 다른 PC 등록, 사용, 업데이트, 중지/제거, 문제 해결 흐름이 문서화되어 있습니다.

§ 01 · Product surface

백엔드 배관만이 아니라 실제 제어면까지

GitHub 저장소의 docs/assets/screenshots에 포함된 모바일 manual screenshots를 제품 증거의 중심에 배치하고, 기존 데스크톱 제품 캡처도 함께 유지했습니다. 채팅, 세션 목록, 권한, 지침, 스킬 화면을 모바일 사용 흐름 기준으로 먼저 보여줍니다.

Source: darkhtk/deskrelay GitHub README and docs/MANUAL.md.

§ 02 · Architecture

원격 UI, 로컬 실행

사이트는 제품처럼 느껴져야 하지만, 민감한 실행 표면은 사용자의 PC에 남아야 합니다.

End-to-end path
Browser → :18193 → :18192 → :18191/:18091 → Claude Code CLI

README 구조도 기준. 서버 PC와 등록 PC의 connector daemon이 각각 로컬 Claude Code CLI를 실행합니다.

site-frontendBrowser UI on :18193
site-backend:18192 and .self-server/state registry
connectorserver :18191, registered PC :18091
Claude CodeCLI logged in on each controlled PC
hub바깥은 제품 shell, 안쪽은 사용자 PC의 runtime authority.
System slices

Frontend. package metadata 기준 @deskrelay/site-frontend는 Solid + Vite SPA이고, @deskrelay/mobile-app은 Capacitor wrapper입니다.

Backend. @deskrelay/site-backend는 self-host Hono/Bun backend이며 브라우저와 사용자가 등록한 connector daemon URL 사이를 연결합니다.

Connector. @deskrelay/pc-connector-daemon은 private HTTP API로 local Claude Code behaviors를 노출하는 self-host connector daemon입니다.

Behavior. @deskrelay/behavior-remote-claude는 사용자의 PC에서 claude CLI를 실행하고 stream-json output을 kernel events로 흘립니다.

§ 03 · Device lifecycle

설치와 등록 흐름이 제품의 뼈대입니다

README는 서버 설치, 접속 URL과 token, 다른 PC 등록, 검증 리포트, 업데이트, 문제 해결을 한 흐름으로 설명합니다.

Install

서버 PC에서 시작

Windows PowerShell 또는 macOS Terminal에서 설치 스크립트를 실행합니다. 설치 후 기본 브라우저는 http://127.0.0.1:18193로 열립니다.

Register

다른 PC 등록 명령

메인 화면의 등록 명령을 제어하려는 Windows PC PowerShell에 붙여넣으면 repo 설치/업데이트, connector 실행, Tailscale/LAN 주소 감지, 서버 접근 검증, 디바이스 등록을 처리합니다.

Operate

디바이스, 세션, 권한, 스킬

왼쪽 드롭다운에서 PC를 고르고, 새 채팅의 작업 디렉토리를 선택하며, 권한 탭과 스킬 탭에서 현재 Claude 환경을 확인합니다.

§ 04 · Trust boundary

private-network 우선, 로컬 권한은 로컬에

README는 connector 포트를 공용 인터넷에 직접 노출하지 말고, 외부 접근이 필요하면 Tailscale 같은 사설 네트워크를 쓰라고 명시합니다. 다른 PC 등록 조건도 같은 LAN 또는 같은 Tailscale tailnet입니다.

문제 해결도 이 경계 안에서 설명됩니다. 디바이스가 목록에 없으면 서버 URL, 같은 LAN/Tailscale, 대상 PC의 18091 포트, 방화벽, registration report, connector 검증 리포트를 순서대로 확인합니다.
